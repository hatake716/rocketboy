# ゲームブログの5記事から選定した15件

> この文書は1.2.0以前の追加履歴です。1.2.1ではWikipedia確認済みの項目に限定しています。[現在の収録内容](WIKIPEDIA_QUOTES.md)。


確認日：2026-09-09。「エンタメ最高マンの家庭用ゲームブログ」のユーザー指定5記事を参照。
各記事から短い表現を3件ずつ選び、既存分との重複を避けて15件をゲームカテゴリに追加した。
ゲームカテゴリは10件から25件、総数は346件から361件に増加。目標3,000件には2,639件不足している。

## 採録範囲と表示

- すべて紹介記事に掲載されている表記。ゲーム内の台詞・音声や、広告の原資料との照合は未実施。
- 『エルシャダイ』の項目は掛け合いの返答だけを収め、「一部抜粋」と表示。
- ストリートファイターの項目はキャッチコピーとして収録し、特定の人物の発言とはしない。
- シリーズ共通の決め台詞、ゲーム内メッセージ、発言者を特定できない項目は作品に帰属させる。詳細は「出典を知る」から説明へ進む。
- 掛け声やフレーズにも、その表現が遊びや物語に与える効果について独自の解説を付ける。
- 作品の歌詞、ブログの解説文や画像、記事全文は同梱しない。
- 引用元の文章・作品に、本リポジトリのMITライセンスを適用しない。

『ROBOTICS;NOTES』の瀬乃宮あき穂の人物名は[公式サイト](https://roboticsnotes.jp/)でも確認した。
『クロノ・トリガー』等の記事に記載のない発言者名を推測で補っていない。

## データと検証

編集元は `data/quotes/entertainment.json`。各項目の番号、抜粋の区別、取得HTMLのSHA-256は `data/quotes/entertainment-provenance.json` に保存。
`tools/quotes/verify_entertainment_sources.py` は記事本文の番号付き項目の中に引用文があることを確認し、コメント欄との取り違えを避ける。
取得時のHTMLはアプリ・リポジトリへ同梱しない。

```sh
python3 tools/quotes/verify_entertainment_sources.py --html-dir /tmp/rocketboy-entertainment
python3 tools/quotes/build_catalog.py
```

記事を再取得する場合は検証コマンドに `--fetch` を追加。記事が更新されていたらハッシュ不一致になるため、内容を再確認してから来歴を更新する。
