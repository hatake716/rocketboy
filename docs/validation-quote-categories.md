# 名言カテゴリ拡張の検証（制作途中）

2026-09-09。既存の1.1.0/code 2に対するローカル変更。新しい完成版リリースではない。
**5カテゴリ・170件が実収録。依頼された3,000件は未達で、残り2,830件。**

## 実装・検証した内容

- 歴史上の人物8件、企業経営者5件、アニメ・漫画3件、ことわざ54件、百人一首100首。
- カテゴリごとの収集数・総数、収集済みの本文・読み・人物名・解説による検索、30件ずつのページ送り。
- 名言詳細から戻ったときの検索語・ページの保持。全100首の個別解説。
- 旧版8件の安定ID・読みを固定し、旧セーブと収集データを引き継ぐ。
- 最長38字の名言で、先頭部分を確定しても発射せず、残りの入力で迎撃・100点・保存。
- 読みの入力・保存上限を64字へ拡大。小さな表示領域では16pxの文字サイズを維持し、入力に応じて続きの行を表示。
- 高さ120〜320論理ピクセル、読み12・33・64字、落下開始・途中・着地直前で名言パネルが枠内に収まることを検証。
- 既存のIME確定・変換、Gboardタップ、着弾3回、再挑戦、BGM、一時停止、称号境界、設定のテストも実行。

## 結果

- 単体テスト23件成功（GameEngineTest 19、RanksTest 4）。
- Android 15 / API 35 / x86_64、Gboard日本語12キー：通常表示18件成功。
- 720×1280 / 320dpiで最長名言の入力・100点・保存・詳細画面のテスト1件成功。
- `assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest`、`lintDebug`、`assembleRelease` 成功。
- Debug Lint：エラー0、警告24。直書き文字列、ライブラリ更新等の警告は残る。
- debug / release APKの `quotes/catalog.tsv` と `authors.tsv` が生成元とバイト一致。新規162件と既存8件を同梱。
- `build_catalog.py --require-target` は終了コード1。**3,000件の要件を満たしたという判定はしていない。**

人物紹介がスクロール不要な場合に、テストがスクロール領域を必須として失敗したため、可視状態を先に調べるよう修正。その後18件すべて成功。
