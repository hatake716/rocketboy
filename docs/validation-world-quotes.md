# 世界の偉人の名言追加の検証

2026-09-09。1.1.0 / code 2 に対するローカル変更の試用版。
ユーザー指定のStudy Languageの名言一覧から人物別の記事を確認し、64件を追加した。
追加の内訳は歴史上の人物59件、企業経営者5件。合計は282件となった。
**目標3,000件の収録作業は未完了で、残り2,718件。**

## 追加内容

- 各項目に短い引用、入力用のひらがな、人物紹介、独自の解説、参照記事URLを用意。
- 全64件の引用本文が、空白を正規化した参照記事本文に存在することを照合。取得HTMLのSHA-256も記録と一致。
- 長い文章からの一部抜粋20件を、アプリ内の表記で区別。
- 発言や著作の原典は未照合。記事に掲載された日本語表記の採録であることと、この確認範囲を各項目の出典欄に明記。
- 孔子とマルクス・アウレリウスは旧版の人物IDと紹介を再利用。既存の名言ID・本文・読みを維持。
- 生成ツールで旧版の人物への参照を許容しつつ、人物IDの重複定義は引き続き拒否。

[64件の人物・カテゴリ・参照記事一覧](WORLD_QUOTES.md)。編集元は `data/quotes/world.json`、
照合記録は `data/quotes/world-provenance.json`。元記事の全文や写真は同梱していない。
