入力する文字列は記事の表記から句読点・記号・空白を外した読み。長い台詞の一部を採った8件は「一部抜粋」と明記する。

## 編集と検証

- `data/quotes/curated.json`：企業・作品の名言と人物。`additional.json` があれば同じスキーマで追加入力できる。
- `data/quotes/animate.json` / `world.json` / `keiziban.json` / `entertainment.json`：指定されたサイトから選定した名言、読み、独自解説と出典。
- `data/quotes/proverbs.tsv`：ことわざ・読み・解説。
- `data/quotes/hyakunin-source.csv` と `hyakunin-explanations.txt`：100首と同順の個別解説。
- `python3 tools/quotes/build_catalog.py`：重複ID・重複本文・重複読み・人物参照・カテゴリ・読み64字上限・解説・出典を検査し、`app/src/main/resources/quotes/*.tsv` と実数集計を生成。
- `python3 tools/quotes/build_catalog.py --require-target`：加えて合計3,000件を必須とする。**現時点は361件なので失敗する。これは未達の要件であり、アプリのビルド成功とは別の判定。**

新しいIDを割り当て、出典・前後の文脈・入力する読み・表示・読みの文字数×300点の加算・保存を検証する。同じ一文の別表記や空の解説を別の収録点数として数えない。
原文・慣用表記・訳・要約を混同しない。入力は最大64字。小画面では読みの行を入力進捗に合わせて切り替えるが、全文一致でのみ迎撃する。

残り2,639件は選定・出典照合・読み作成・個別解説が未完了。3,000件を満たす完成版の検証はまだ行えない。
