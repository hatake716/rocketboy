# ROCKETBOY 天体の配色

1.5.0で追加。ドット絵の少数色表示を保ち、訓練生と25天体にそれぞれ専用の色を割り当てます。天体をイメージしたゲーム用の配色で、実際の天体の色を正確に再現するものではありません。

プレイ中は現在の挑戦のスコアで判定し、4,000点ごとに変更。タイトル・メニューは自己ベストの到達色です。一時停止・途中再開・結果はその挑戦の色を保ちます。新規開始・再挑戦は訓練生から。競技のスコア画像も結果のスコアで色が決まり、画面を再生成しても同じ色になります。

## 表示と保存

- 背景・地球・ロケット・隕石・名言・下線・スコア・入力欄・ボタン・進捗バーを同じ配色で表示。
- 入力欄を交換せず色を更新するため、日本語IMEの変換中テキストとフォーカスを保持。
- 色のための追加セーブ形式は不要。既存の保存スコアから復元。
- キーボードアプリの配色は変更しません。
- `CelestialPalettes.kt` に不変の色セットを定義。画面ごとにスコアから選ぶため、結果画像を作成しても他の画面の色へ影響しません。
