# 名言の収録方針と出典（1.3.0）

現在の名言の出典はすべて日本語版Wikipediaです。本文と帰属を確認した228件を収録しています。1.2.1から56件追加しました。

- [収録数・出典一覧・確認方法](WIKIPEDIA_QUOTES.md)
- [現在の編集元](../data/quotes/wikipedia.json)
- [採用228件と削除189件の記録](../data/quotes/wikipedia-audit.json)
- [Wikipediaの固定版を再取得した照合結果](../data/quotes/wikipedia-verification.json)
- [ゲーム内の利用表示](../app/src/main/assets/licenses/Wikipedia-Reuse.txt)

[今回の調査記録](../data/quotes/wikipedia-expansion.json) に検索範囲と追加項目を保存しています。全Wikipediaの網羅や3,000件への到達はしていません。本文・人物・作品への帰属を確認したものだけを収録します。
旧サイトの編集データは追加履歴として保存していますが、アプリの収録データ生成には使用しません。
[1.2.0以前の追加・参照履歴](quotes-before-wikipedia.md) は現在の収録一覧ではありません。
