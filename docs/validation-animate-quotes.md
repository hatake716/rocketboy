# アニメイトタイムズからの名言追加の検証

2026-09-09。1.1.0 / code 2 に対するローカル変更の試用版。
指定の名言一覧からリンクされた48記事を参照し、アニメ・漫画作品の台詞を48件追加した。
既存3件と合わせてこのカテゴリは51件、全カテゴリでは218件。
**目標3,000件の収録作業は未完了で、残り2,782件。**

## 内容と画面

- 48件すべてに入力用のひらがな、個別の解説、人物紹介、作品名、参照記事へのリンクを用意。
- 各記事から短い台詞を1件選定。8件の部分引用は「記事掲載台詞の一部抜粋」と表示。
- 全48件について、空白を正規化した本文が参照記事に存在することを照合。取得したHTMLのSHA-256も記録と一致。
- コレクションの一覧と詳細に作品名を表示。収集済み名言を作品名でも検索できる。
- 既存の名言ID・人物IDを維持。ナルトの追加名言は既存の人物紹介に関連付ける。

参照先の対応表は [ANIME_QUOTES.md](ANIME_QUOTES.md)、編集元は `data/quotes/animate.json`、
照合記録は `data/quotes/animate-provenance.json`。記事全文・画像はアプリやリポジトリに同梱しない。
