# Play Console 申告・審査入力案

2026-09-16 / ROCKETBOY 1.5.0（10）の更新用資料。今回の配色と複数行下線の変更では、権限・SDK・データ収集・外部共有・名言内容・保存形式を変更していません。以下は1.4.1で用意した回答案を引き継いだものです。Console上の既存申告・IARC取得状況は今回照会していません。実際の登録内容との差分を確認して利用してください。IARC認定やGoogleの審査通過を示す資料ではありません。

## アプリへのアクセス

**すべての機能を、ログイン等の特別なアクセスなしで利用できます。** テストアカウント・パスワード・有料会員・地域限定コードはありません。日本語キーボードを有効にしてください。

審査メモ案：

> 本アプリはオフラインの日本語タイピングゲームです。アカウントは不要です。「ミッション開始」で遊べます。ひらがなの読みを確定するか「発射」を押して隕石を迎撃してください。「プレイ設定・モード選択」から通常・名言・競技を選べます。名言は迎撃するとコレクションで本文・解説・出典を読めます。BGM試聴室では最初から全26曲を再生できます。競技モードの結果画面は画像と文章を外部共有アプリへ渡す機能で、自動投稿しません。プライバシーポリシーは「遊び方・設定」の下部にあります。

## Data safety

回答案は **「開発者によるデータ収集なし」**、**「申告対象のデータ共有なし」** です。外部共有とOSバックアップを隠す意味ではありません。下表を確認して、実際の質問票の分岐に従います。

| データ・操作 | 処理と保存先 | 申告時の扱い |
|---|---|---|
| 入力したひらがな | 端末内で迎撃判定。開発者のサーバーへの送信なし | オンデバイス処理 |
| ミッション、最高得点、トップ10、収集ID、音設定 | Androidのアプリ専用SharedPreferences | 端末内の保存。開発者によるオフデバイス収集なし |
| スコア画像と共有文章 | 利用者が明示的に選んだ外部アプリへACTION_SENDで渡す | 利用者が期待する明示的な共有操作の例外として回答案を作成。実態が変わる場合は再判定 |
| Androidバックアップ・端末移行 | allowBackup=true。利用者のOS/アカウント設定に従う | OS機能であり開発者は受信しない。プライバシーポリシーには明記 |
| 出典・ライセンスリンク | 外部ブラウザーへURLを渡す | 外部サービスの処理は各サービスの規約に従う |
| サポートメール | 利用者が任意にメールで連絡 | メールアドレス・本文は返信と問題調査に使用。ゲームの自動送信はない |
| 日本語キーボード | 利用者が選んだ端末のIME | キーボード提供者のデータ取扱いは別途確認が必要 |

全項目を「いいえ」で機械的に埋めず、収集なしを選択した後にConsoleが表示する必要な質問だけに答えてください。データ転送時の暗号化は、本アプリの開発者宛通信がないため、その通信に対して「暗号化済み」と主張しません。独立したセキュリティ審査・認証は取得していません。

実装根拠：`AndroidManifest.xml` とマージ後release manifest、`SessionStore.kt`、`CompetitiveScore.kt`、`MainActivity.kt`、Gradle依存関係。第三者の広告・計測・ログ送信SDKは含みません。AndroidXの内部レシーバー用signature権限はありますが、ユーザーデータへの実行時許可ではありません。

[GoogleのData safety説明](https://support.google.com/googleplay/android-developer/answer/10787469)のオンデバイス処理と、利用者主導の共有に関する定義を確認しました。収集・共有の回答と[プライバシーポリシーの要件](https://support.google.com/googleplay/android-developer/answer/10144311)を一致させてください。

## 対象年齢・Families

開発者の指定は **子どもを含む全年齢** です。対象年齢のチェックボックスは「5歳以下」「6〜8歳」「9〜12歳」「13〜15歳」「16〜17歳」「18歳以上」の各層で設計・内容を確認してから確定します。とくに幼児層の日本語入力・時間制限の操作確認は未実施です。

広告・購入・位置情報・識別子収集はありません。一方、Xへ共有する機能と外部リンクがあり、一部の引用・解説には死や戦闘・恐怖の表現があります。[PLAY_CONTENT_REVIEW.md](PLAY_CONTENT_REVIEW.md)の内容確認と保護者向け操作の実装確認が必要です。現時点でFamilies準拠済みとは申告できません。

[Google Play Familiesポリシー](https://support.google.com/googleplay/android-developer/answer/9893335)では、対象の子どもに適した内容や、該当するソーシャル機能の注意表示・保護者管理・成人による操作等が求められます。単に対象年齢を「全年齢」と入力するだけでは完了しません。

## IARC 内容レーティング

**Console上の現在のレーティングは未確認**。以前のローカル準備記録には未取得とあります。審査用メールはacesmash@gmail.com。登録済みの質問票があれば回答と実装を照合し、実際の設問の定義に沿って次の事実を確認します。

- プレイヤーはロケットで非生物の隕石を迎撃する。ドット絵の爆発、地球への着弾、画面フラッシュがある。人や動物の負傷・血・写実的な残虐描写はない。
- 名言と解説には死・戦闘・狙撃・悪魔などを示す文章がある。「暴力・恐怖の表現は一切なし」とは回答しない。
- 百人一首には恋愛を詠む歌がある。性的描写の有無は翻訳・解説も含めて確認する。
- 金銭を賭ける機能、現金や価値ある賞品、ルートボックス、購入はない。
- ゲーム内チャット、オンライン対戦、他人の投稿を閲覧する機能はない。結果を外部サービスへ共有できることは、情報交換等の関連設問の定義に応じて開示する。
- Webへの出典リンクがある。外部サービスのアカウントや投稿画面はROCKETBOY内の機能ではないが、到達できる内容の確認が必要。

引用元作品そのものの年齢指定を本アプリの年齢に置き換えたり、反対に短い引用だから無条件に全年齢と判断したりしないでください。実際に表示される文字と動作を基に回答します。
