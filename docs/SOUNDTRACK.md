# CELESTIAL ADVENTURE — ROCKETBOY 1.3.1

訓練生の「ORBIT RUNNER」を維持し、25天体のBGMをすべて新規作曲に置き換えました。各曲64小節・4/4拍子、152〜194 BPM、約79〜101秒のループです。宇宙を冒険する期待感を共通のテーマにし、各天体を異なる旋律・リズム・音色・伴奏で表現しています。

## 和声と展開

全曲の和声は **♭VI → ♭VII → i → i** の4小節ループです。例えばイ短調の地球・ケレス・カリスト・天王星・冥王星では **F → G → Am → Am**。ここでは、[東方楽曲の和声分析資料の「ZUN進行 基本形」（書籍内75ページ、PDFの6ページ目）](https://harimusic.net/pdf/trial002.pdf#page=6)で説明されている **♭VI → ♭VII → i** を採用しています。コード進行を創作の土台とし、各曲の旋律はこのゲーム用に新たに作曲しました。

各曲に4小節の主題A・サビB・中間部Cを個別に記譜。各8小節の **A → Aの変奏 → B → Bの変奏 → C → Cの変奏 → Aの高音再現 → Bの再現** に展開します。反復の後半は応答の終わり方を変え、長い音には短い装飾句を加えています。最後の小節は次の周回につながる助走です。

天体の特徴は音楽上の着想です。天体の実測音や探査機の録音ではありません。

## 音源

矩形波2声（12.5%・25%・50%デューティ）、32サンプル・4bit波形メモリ1声、7/15bit LFSRノイズ1声。主旋律・分散和音と応答・ベース・打楽器をそれぞれ1声で再生します。キック・スネア・ハイハットは1つのノイズ声を共有し、同時発音数は最大4声です。

[Pan Docsの音源レジスタ資料](https://github.com/gbdev/pandocs/blob/master/src/Audio_Registers.md)を参照し、矩形波・波形メモリの周波数をGBのタイマー値に丸め、ノイズにも設定可能な周波数を使っています。ゲームボーイ音源の構成を再現したソフトウェア合成です。実機APUの完全エミュレーションや実機録音ではありません。

スマホでの再生に合わせ、2倍オーバーサンプリング・短い発音端の処理・出力フィルターでクリックと高域の粗さを抑えています。出力のピークを緩やかに抑え、疎なリズムの曲と音の密な曲で音量差が出すぎないようにしています。フィルター前後に波形を周期的に延長し、ループ境界の状態もそろえます。外部サンプル・MIDI・ゲームROM音源は使用していません。

44100 Hz・16-bit・モノラルWAVを作り、Ogg Vorbis品質5に変換して同梱します。訓練生と効果音5種はバイト単位で変更していません。

## 再生成

Python 3、NumPy、FFmpeg（libvorbis）が必要です。

```bash
python3 tools/music/render.py
```

譜面は `tools/music/scorebook.py`。全曲のWAV・音符イベント・小節ごとの和声は `artifacts/1.3.1/soundtrack/`、同梱Oggは `app/src/main/res/raw/bgm_*.ogg`、ハッシュ・ピーク・実効値・ループ境界の測定値は `data/music/tracks.json` に出力します。

一部の曲を試作する場合は `--only earth jupiter` を指定します。WAVとOggを出力フォルダーだけに保存し、アプリの音源・全曲のマニフェストは更新しません。`--export-dir` で出力先を変更できます。
