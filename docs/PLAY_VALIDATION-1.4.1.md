## 実際のリリース版の確認

Android 15 / API 35、1080×1920、360dpiの使い捨てエミュレーター `emulator-5556` で確認。既存AVDを `-read-only -no-snapshot` で別起動し、通常の `emulator-5554` と分離しました。

通常のrelease APKで1テスト成功。その後、**AABから生成したuniversal APKを上書きインストールし、同じシナリオの1テストが成功**。テストはR8後のクラスへ直接アクセスせず、プラットフォームAPI・画面操作・入力欄・実際の発射ボタンを使います。

確認した結果：

- パッケージから1.4.1と非debuggableを確認。
- 通常モードで「そら」を入力して発射し、20点を取得。
- 名言モードでデカルトの読み12文字を入力し、3,636点を取得。迎撃エフェクトとコレクション保存を確認。
- 競技モードで20点を取得後、1回の着弾で結果画面へ遷移。スコア画像、共有ボタン、#rocketboyの文章を確認。
- 名言集で228件・6カテゴリを表示。
- BGM試聴室で地球の曲を再生し、再生中・停止中への変化を確認。
- プライバシーポリシー本文・連絡先・戻る操作を確認。
- 自己ベストトップ10に3,636点の記録を表示。
- AAB由来のAPKを終了してコールド起動し、最高得点3,636点の保存を再確認。
- 最終検証区間のAndroidクラッシュバッファにクラッシュ記録なし。

撮影には再現可能な保存ミッションを設定し、隕石の語・位置・速度を固定しています。画像は実際のリリース版から撮影し、得点・キーボード・ゲームの画面を外部で作り足していません。キーボードはGboardの日本語12キー。テスト入力はアクセシビリティ経由の入力欄設定と発射ボタンであり、人のフリック入力速度を測ったものではありません。
