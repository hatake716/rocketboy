# ROCKETBOY 30秒紹介動画

成果物は `artifacts/promo-30s/ROCKETBOY-30s-Short-1080x1920.mp4`。アプリ本体を変更せず、1.4.0のAndroidエミュレーター録画を編集した縦型動画です。

| 時間 | 内容 |
|---|---|
| 0–2.5秒 | タイトルと「その一文字が、地球を救う。」 |
| 2.5–8秒 | ひらがな入力からロケット迎撃 |
| 8–13秒 | 名言の全文入力と撃破エフェクト |
| 13–16秒 | 6カテゴリの名言コレクション |
| 16–21秒 | 残機1・速度1.5倍の競技モードと終了 |
| 21–23秒 | スコア画像と #rocketboy の共有画面 |
| 23–26秒 | 全26曲のBGM試聴室 |
| 26–30秒 | 「目指せ、冥王星ランク。」とタイトル |

映像は紹介用デモです。`PromoCaptureTest`で隕石の位置・お題・サンプルの収集状態を用意し、本物のGameEngine・PixelScene・AndroidのIME確定処理を動かしています。スコア画面・ゲームの演出を合成で捏造していません。文字は1文字ずつ入力していますが、物理的な指の操作を録画したものではありません。Xへの実投稿は行っていません。

音楽はゲーム内の地球BGM「青い星からの出航」（172 BPM）。発射・迎撃・着弾・ランクアップの効果音もゲーム内素材です。30秒の紹介用サウンドトラックとして映像に合わせて編集しています。ナレーションはありません。フォントはゲームと同じDotGothic16です。

## 再編集

必要なものは Python 3、Pillow、FFmpeg（libx264とAAC）。ルートディレクトリから以下を実行します。

```bash
python3 tools/promo/render_short.py
```

編集内容は `render_short.py` の `SCENES` にまとまっています。既存の映像区間を維持して音声・結合のみ再出力する場合は `--reuse-segments` を指定できます。映像・字幕を変更した場合は再利用オプションを外してください。

`artifacts/promo-30s/source` に元のMP4、`source/promo/capture.json` に発射等のタイミング、`edit.json` に編集区間、`sound-cues.json` に効果音の配置を保存しています。録画時の発射キューは最後の入力文字の待機後に記録するため、編集側で既知の待機時間と録画の開始遅延を補正しています。

録画用テストは `app/src/androidTest/java/io/github/hatake716/rocketboy/PromoCaptureTest.kt`。実行先をエミュレーターに限定するガードがあります。録画には1080×1920 / 360dpiを使いました。録画後はエミュレーターの画面設定と元のSharedPreferencesを復元済み。物理端末への入力・更新インストールは行っていません。

## 確認

- H.264 / yuv420p / 1080×1920 / 30fps / 900フレーム。
- 映像・音声とも30.000秒。AAC / 48kHz / ステレオ。
- 全体をデコードしてエラーなし。
- 完成版の各場面と名言撃破時のフレームを目視確認。
- 完成版AACの実測は約 -15.0 LUFS、true peak -4.5 dBFS。
- アプリ本体のAPKのSHA-256は1.4.0の配布済み成果物と一致。

最終メディアの検証値は `artifacts/promo-30s/validation.json`、サムネイルは `artifacts/promo-30s/cover.png` にあります。
